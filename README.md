# 📅 Planner Solving

Инструмент для разбора групповых расписаний Excel и формирования сводного расписания преподавателей. Система рассчитана на книги с различными строками начала, столбцами недель, размерами дневных блоков, объединёнными ячейками и разным оформлением.

Главное изменение: файл больше не обрабатывается вслепую. Сначала выполняется автоматический анализ, затем оператор видит исходный лист, проверяет или исправляет координаты и запускает контрольный разбор. Итоговый файл формируется только после проверки.

## Что умеет система

- автоматически искать строку учебных недель и диапазон недельных столбцов;
- определять строку месяцев, начало и конец сетки занятий;
- оценивать число пар, шаг строк и размер блока учебного дня;
- находить нижний блок дисциплин, лекторов и других преподавателей;
- учитывать объединённые ячейки без изменения исходной книги;
- разбирать два основных варианта: отдельные строки «код / дисциплина / аудитория» и многострочное занятие в одной ячейке;
- брать преподавателя из нижнего блока, из самой сетки или из обоих источников;
- показывать уверенность анализа, замечания, найденные занятия и неназначенные дисциплины;
- сохранять пользовательские шаблоны разметки в браузере;
- обрабатывать несколько файлов с собственной разметкой для каждого;
- формировать общее и недельное расписание;
- работать полностью автономно, без внешних сетевых ресурсов.

## Рабочий процесс оператора

1. Загрузить один или несколько файлов `.xlsx` или `.xlsm`.
2. Для каждого файла проверить найденный лист, строку недель и подсвеченную сетку.
3. Переключиться на область «Дисциплины и преподаватели» и проверить границы нижнего блока и его столбцы.
4. При необходимости исправить координаты. Номера в форме совпадают с номерами строк и столбцов Excel; рядом со столбцами показывается буквенное обозначение.
5. Нажать **«Проверить разметку файла»**. Система покажет число занятий, число назначений преподавателей, ошибки и примеры распознанных записей.
6. Проверить все включённые файлы и нажать **«Сформировать расписание»**.

Подробное руководство: [`docs/OPERATOR_GUIDE.md`](docs/OPERATOR_GUIDE.md). Результаты технического аудита: [`docs/AUDIT.md`](docs/AUDIT.md).

## Быстрый запуск

Требуется Python 3.11 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
./start_web.sh
```

Интерфейс будет доступен по адресу `http://localhost:8000`.

Для серверного запуска:

```bash
uvicorn web.backend.main:app --host 127.0.0.1 --port 8000
```

## Проверка

```bash
pytest -q tests
```

Проверки охватывают:

- расписание со смещённой строкой недель и нижним блоком в произвольных столбцах;
- расписание с многострочным занятием в одной ячейке;
- ошибки координат разметки;
- календарное преобразование недель;
- полный запросный цикл «анализ → проверка → формирование».

## Структура

```text
src/
  schedule_analyzer.py   # поиск структуры, оценка уверенности, предпросмотр
  data_loader.py         # разбор по подтверждённой разметке
  transformer.py         # преобразование занятий в сетку преподавателей
  exporter.py            # итоговый Excel
  weekly_exporter.py     # недельный вариант
web/
  backend/               # FastAPI и сеансы анализа
  frontend/              # автономный интерфейс Vue без сборщика
input/analysis_sessions/ # временные загруженные книги, удаляются автоматически
output/                  # сформированные файлы
docs/                    # аудит и руководство оператора
```

## Поддерживаемые исходные данные

Поддерживаются `.xlsx` и `.xlsm`. Старый двоичный формат `.xls` необходимо открыть в Excel или LibreOffice и сохранить как `.xlsx`. Это сделано намеренно: разбор `.xls` требует отдельного устаревшего движка и не поддерживает часть сведений об объединениях и оформлении.

Система анализирует значения ячеек, геометрию и объединения. Шрифт, цвет, размер текста и точные координаты исходного шаблона не являются обязательными признаками. Книги, где расписание представлено изображением, объектами рисования или защищёнными листами без доступных значений ячеек, требуют предварительного преобразования.

## Безопасность и хранение

- исходные имена файлов очищаются;
- загрузки сохраняются под случайными идентификаторами;
- размер одного файла ограничен 50 МБ;
- временные сеансы удаляются через 24 часа;
- пути скачивания проверяются;
- `teachers.json` записывается атомарно;
- внешние службы и сетевые шрифты не используются.
