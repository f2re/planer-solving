# 📅 Planner Solving

Инструмент для разбора групповых расписаний Excel и формирования сводного расписания преподавателей. Система рассчитана на книги с различными строками начала, столбцами недель, размерами дневных блоков, объединёнными ячейками и разным оформлением.

Файл не обрабатывается вслепую: сначала выполняется автоматический анализ, затем оператор проверяет или исправляет координаты и запускает контрольный разбор. Итоговый файл формируется только после проверки.

## Пространства

Данные разделены на независимые рабочие пространства. Пространство удобно использовать для отдельной кафедры, факультета, филиала, семестра или проекта.

В каждом пространстве хранятся:

- собственный список преподавателей;
- название, описание и цвет интерфейса;
- серверные шаблоны разметки Excel;
- даты начала и окончания семестра;
- настройки, применяемые при формировании итогового расписания.

Существующий `teachers.json` автоматически переносится в **Основное пространство**. Оно также синхронизируется обратно в `teachers.json`, поэтому старые CLI-сценарии продолжают работать.

### Импорт и экспорт

- пространство целиком: переносимый JSON-пакет с преподавателями, шаблонами и настройками;
- преподаватели: CSV с разделителем `;` или JSON;
- шаблоны разметки: JSON;
- импорт можно выполнить с добавлением записей либо с полной заменой текущего набора;
- при добавлении дубликаты по ФИО пропускаются и отражаются в отчёте.

Подробное руководство: [`docs/WORKSPACES.md`](docs/WORKSPACES.md).

## Что умеет система

- автоматически искать строку учебных недель и диапазон недельных столбцов;
- определять строку месяцев, начало и конец сетки занятий;
- оценивать число пар, шаг строк и размер блока учебного дня;
- находить нижний блок дисциплин, лекторов и других преподавателей;
- учитывать объединённые ячейки без изменения исходной книги;
- разбирать отдельные строки «код / дисциплина / аудитория» и многострочное занятие в одной ячейке;
- брать преподавателя из нижнего блока, из самой сетки или из обоих источников;
- показывать уверенность анализа, замечания, найденные занятия и неназначенные дисциплины;
- сохранять и редактировать шаблоны на сервере внутри пространства;
- обрабатывать несколько файлов с собственной разметкой для каждого;
- формировать общее и недельное расписание;
- работать автономно, без внешних сетевых ресурсов.

## Рабочий процесс оператора

1. Выбрать пространство в верхней панели.
2. При необходимости открыть **Управление** и проверить преподавателей, шаблоны и даты семестра.
3. Загрузить один или несколько файлов `.xlsx` или `.xlsm`.
4. Для каждого файла проверить лист, строку недель и подсвеченную сетку.
5. Переключиться на область «Дисциплины и преподаватели» и проверить нижний блок.
6. Исправить координаты и нажать **«Проверить разметку файла»**.
7. Сохранить исправленную разметку как новый шаблон либо обновить существующий.
8. Проверить все включённые файлы и сформировать расписание.

Руководство по разметке: [`docs/OPERATOR_GUIDE.md`](docs/OPERATOR_GUIDE.md). Технический аудит: [`docs/AUDIT.md`](docs/AUDIT.md). Повторный аудит и дальнейший план: [`docs/AUDIT_WORKSPACES.md`](docs/AUDIT_WORKSPACES.md).

## Быстрый запуск

Требуется Python 3.11 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
./start_web.sh
```

Интерфейс: `http://localhost:8000`.

## Проверка

```bash
pytest -q tests
```

Проверки охватывают анализ Excel, операторский API-сценарий, миграцию `teachers.json`, изоляцию пространств, импорт/экспорт, редактирование шаблонов и защиту от удаления последнего пространства.

## Структура

```text
src/
  schedule_analyzer.py   # поиск структуры, оценка уверенности, предпросмотр
  data_loader.py         # разбор по подтверждённой разметке
  workspace_store.py     # пространства, преподаватели, шаблоны, миграция
  transformer.py         # преобразование занятий в сетку преподавателей
  exporter.py            # итоговый Excel
  weekly_exporter.py     # недельный вариант
web/
  backend/               # FastAPI, пространства и сеансы анализа
  frontend/              # автономный интерфейс Vue без сборщика
data/workspaces.json     # рабочие пространства, создаётся автоматически
input/analysis_sessions/ # временные загруженные книги, удаляются автоматически
output/                  # сформированные файлы
docs/                    # аудит и руководства
```

## Поддерживаемые исходные данные

Поддерживаются `.xlsx` и `.xlsm`. Старый `.xls` необходимо открыть в Excel или LibreOffice и сохранить как `.xlsx`. Книги, где расписание представлено изображением, объектами рисования или защищёнными листами без доступных значений ячеек, требуют предварительного преобразования.

## Безопасность и хранение

- JSON-хранилище записывается атомарно через временный файл;
- нельзя удалить последнее пространство;
- исходные имена загрузок очищаются;
- размер расписания ограничен 50 МБ, импортируемого справочника — 5 МБ;
- временные сеансы удаляются через 24 часа;
- пути скачивания проверяются;
- внешние службы и сетевые шрифты не используются.
