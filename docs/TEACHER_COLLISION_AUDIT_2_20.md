# Аудит и разрешение коллизий преподавателей — 2.20

## Выявленные причины

Прежний алгоритм назначал преподавателя во время чтения каждого файла. Он не видел расписание целиком, не сохранял полный набор допустимых преподавателей дисциплины и при исчерпании свободных вариантов оставлял занятие у уже занятого преподавателя. В результате предупреждение создавалось, но коллизия фактически сохранялась.

Индекс ФИО также был небезопасен для однофамильцев: один текстовый псевдоним соответствовал одному значению и мог быть перезаписан. Фамилия без инициалов разрешалась без достаточной проверки однозначности.

Интерфейс разрывал единый рабочий процесс: основная кнопка формирования находилась вне полноэкранного редактора, результат не возвращал к текущему сеансу, а история не выбирала новый запуск автоматически. Точные координаты разметки занимали слишком много места и конкурировали с типовыми действиями.

## Реализованная модель идентичности

Преподаватель определяется канонической парой «фамилия + инициалы». Поддерживаются формы:

- `Иванов И.И.`;
- `И.И. Иванов`;
- полное ФИО;
- варианты с разным количеством пробелов и точек.

Псевдоним хранит список совпадений. Фамилия без инициалов назначается автоматически только при единственном кандидате. При нескольких однофамильцах система просит указать инициалы и не делает рискованного выбора.

## Граф назначения

После разбора всех файлов строятся единицы назначения. Параллельные группы объединяются в одну единицу только при совпадении дисциплины, типа занятия и аудитории. Для каждого временного слота решается двудольная задача «занятия — преподаватели».

Порядок ограничений и предпочтений:

1. ручное назначение оператора — жёсткое ограничение;
2. явно извлечённый преподаватель — сильное предпочтение;
3. соответствие роли: лектор для лекции, остальные преподаватели дисциплины для практических и иных занятий;
4. отсутствие занятости в том же слоте;
5. минимальная нагрузка по дисциплине;
6. минимальная общая нагрузка;
7. детерминированный порядок для воспроизводимости.

Резервный преподаватель другой роли допускается только из списка преподавателей этой дисциплины и только как обоснованное средство устранения коллизии. Если безопасного назначения нет, занятие помещается в раздел `Не назначен`; двойная занятость не скрывается.

В отчёте сохраняются исходное и итоговое назначение, кандидаты, роль, причина решения, баланс нагрузки и перечень неразрешённых случаев.

## Семантические группы

Сообщения группируются по смыслу и приоритету:

1. конфликты занятий;
2. технические сбои;
3. преподаватели;
4. разметка;
5. исходные файлы;
6. формирование файлов;
7. даты и календарь;
8. автоматические решения.

Последовательная смена месяца, восстановленная дата и иные нормальные календарные решения отображаются как информация. Неразрешённая двойная занятость отображается как проблема высокой важности. Повторяющиеся сообщения сворачиваются в одну группу с количеством и деталями.

## Новый рабочий поток

- В полноэкранной таблице доступна кнопка `Сформировать`.
- Кнопка `Выйти` заменена на `К обычному виду`; выход больше не является условием формирования.
- Результат содержит действие `Вернуться к исправлениям` и сохраняет текущий `session_id`, файлы, разметку, даты и назначения.
- Новый `run_id` сразу загружается и выбирается в истории.
- История показывает те же смысловые группы и решения, что экран результата.
- Точные координаты перенесены в раскрываемый экспертный раздел.
- Панели получили минимальную ширину, изменение размера и адаптивный режим для 1366×768 и увеличенного масштаба интерфейса.
- Все стили и значки остаются локальными; внешние ресурсы не требуются.

## Регрессионный контракт

Проверяются:

- однофамильцы с разными инициалами;
- перенос занятия свободному преподавателю дисциплины;
- приоритет лектора и практического преподавателя;
- равномерное распределение эквивалентной нагрузки;
- невозможная коллизия без скрытой двойной занятости;
- смысловая группировка и приоритет сообщений;
- формирование из полноэкранной таблицы;
- возврат к тому же сеансу;
- автоматическая связь результата с историей;
- локальные адаптивные стили и экспертный режим разметки.
