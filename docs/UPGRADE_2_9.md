# Обновление с 2.5 на 2.9

1. Остановите службу или используйте штатный офлайн-установщик.
2. Сохраните весь каталог `data`, включая SQLite и WAL.
3. Обновите код.
4. Запустите `bash start_web.sh`.
5. Убедитесь, что `/api/health` сообщает операционную схему версии 4.
6. Откройте интерфейс и создайте первоначального администратора.
7. Добавьте операторов и пользователей просмотра.
8. Проверьте существующие шаблоны: для каждого автоматически создана ревизия №1.

Операционная миграция идемпотентна. База с более новой версией не будет изменена старым приложением.
