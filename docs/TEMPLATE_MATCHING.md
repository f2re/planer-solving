# Автоподбор шаблонов и интерактивная разметка

## Где хранятся шаблоны

Шаблон принадлежит рабочему пространству и хранится в `data/workspaces.json` внутри массива `templates` соответствующего пространства. Запись содержит идентификатор, название, описание, даты создания/изменения и полный объект `layout` с координатами парсера.

Шаблон не привязан к имени исходного файла. После ручной коррекции оператор сохраняет фактически подтверждённую разметку, и она становится кандидатом для следующих книг этого пространства.

## Как выбирается шаблон

После потоковой загрузки выполняются два этапа:

1. базовый автоматический поиск структуры книги;
2. контрольный запуск реального парсера с автоматической разметкой и с каждым сохранённым шаблоном.

Для каждого варианта учитываются:

- число уникальных распознанных занятий;
- число занятий с определённым преподавателем;
- количество найденных недель и дисциплин;
- заполненность блока дисциплин;
- дубли занятий;
- нераспознанные преподаватели;
- пустые недельные столбцы;
- предупреждения и критические ошибки.

Вариант с критической ошибкой не может считаться пригодным. При полном равенстве остаётся базовая автоматическая разметка. Результаты проверки сохраняются в манифесте временного сеанса, а сами шаблоны не изменяются автоматически.

## Коррекция оператором

Предпросмотр книги отображается как HTML-таблица с номерами строк и буквами столбцов. Над таблицей выбирается назначение выделяемой области:

- сетка занятий;
- строка недель;
- строка месяцев;
- блок дисциплин и преподавателей;
- отдельные столбцы обозначения, дисциплины, лектора и остальных преподавателей.

Оператор проводит указателем или пальцем по таблице. Выбранный диапазон сразу переносится в параметры разметки и подсвечивает будущую область парсинга. `Alt/Option` с перетаскиванием перемещает уже выделенный диапазон. Доступны отмена последнего изменения и управление с клавиатуры через `Enter`/`Пробел` на ячейке.

После контрольной проверки исправленную разметку можно сохранить как новый шаблон или обновить существующий. При следующих загрузках она будет проверена автоматически наравне с остальными.

## Загрузка файлов

Приложение не задаёт фиксированного ограничения на количество и размер файлов расписаний. Каждый файл записывается на диск блоками по 1 МБ и не загружается целиком в оперативную память. Фактический предел определяется свободным местом, настройками обратного прокси, файловой системой и ресурсами сервера.
