# Полноэкранная рабочая область разметки

Начиная с версии 2.11 этап разметки открывается как рабочий лист на весь экран. Лист занимает основную площадь, а список файлов, параметры и точные инструменты являются сворачиваемыми плавающими панелями.

## Основные действия

В верхней панели доступны:

- **Файлы** — показать или скрыть список загруженных книг;
- **Параметры** — показать или скрыть числовые параметры;
- **Разметка** — показать компактные инструменты диапазонов и точной структуры;
- **− / +** — изменить масштаб;
- **По экрану** — автоматически подобрать масштаб по ширине и высоте;
- **Авто** — включить или отключить автоматический пересчёт;
- **Пересчитать** — немедленно обновить проверку;
- **Сохранить изменения** — сохранить текущую структуру как шаблон;
- **Выйти** — завершить полноэкранный режим.

Панели файлов и параметров можно перетаскивать за кнопку `⠿`. Их положение не влияет на разметку.

## Реактивный пересчёт

После изменения координат интерфейс:

1. синхронизирует точные списки недель, дней и пар с числовыми полями;
2. немедленно меняет подсветку в таблице;
3. сбрасывает прежнюю проверку;
4. через короткую паузу повторно запускает парсер;
5. показывает состояние **Проверено**, **Есть замечания** или **Ошибка**.

Кнопка **Обновить** больше не требуется для обычной работы. Она остаётся только как ручной аварийный способ загрузить область повторно.

Если изменить `Первый столбец недель`, `Последний столбец недель`, шаг или смещение данных, точные массивы `week_columns`, `week_data_columns` и `week_numbers` перестраиваются автоматически.

## Выделение строк и столбцов

- щелчок по номеру строки выбирает строку;
- `Shift` + щелчок по другому номеру выбирает диапазон строк;
- щелчок по букве столбца выбирает столбец;
- `Shift` + щелчок выбирает диапазон столбцов;
- щелчок по левому верхнему углу выбирает загруженную область;
- обычное протягивание по ячейкам сохранено;
- при протягивании к краю рабочая область автоматически прокручивается.

Выбранный диапазон применяется в соответствии с активным назначением: сетка, недели, месяцы, блок дисциплин или отдельный столбец.

## Масштаб

При входе лист загружается целиком в пределах 500 строк и 160 столбцов и подгоняется под экран. Для более крупных книг интерфейс сообщает об ограничении, а нужную область можно открыть обычным региональным просмотром.

`Ctrl` + колесо мыши изменяет масштаб. Заголовки строк и столбцов остаются закреплёнными при прокрутке.

## Сохранение шаблона

После успешного пересчёта кнопка сохранения предлагает имя автоматически:

```text
<группа или имя файла> · <лист>
```

Если выбран существующий шаблон, можно обновить его или сохранить новый. При выходе с несохранёнными изменениями появляется диалог с тремя действиями:

- сохранить;
- продолжить работу;
- выйти без сохранения шаблона.

Текущая разметка сеанса при выходе не уничтожается; решение относится только к серверному шаблону.
