# Planner Solving 2.9 — кратко

Версия 2.9 завершает этапы 2.6–2.9:

- мастер импорта с предпросмотром, сопоставлением и подтверждением;
- неизменяемые ревизии шаблонов, сравнение и откат;
- составные шаблоны и структурные отпечатки книг;
- обучение на подтверждённых оператором форматах;
- история обработок с исходниками, отчётами и результатами;
- повтор запуска из истории;
- локальные пользователи и роли;
- CSRF-защита и HttpOnly-сеансы;
- административный журнал действий.

Полное руководство: [`OPERATIONS_SUITE.md`](OPERATIONS_SUITE.md).
