# Руководство оператора

## 1. Загрузка

Загрузите все имеющиеся расписания. Не требуется заранее делить файлы по семестрам или исправлять их в Excel. Каждый файл сохраняется в текущем сеансе и остаётся доступным для правки до завершения работы.

Система автоматически:

1. выбирает лист;
2. ищет учебные недели;
3. распознаёт месяцы и даты;
4. определяет строки дней и пар;
5. определяет слои занятия;
6. ищет дисциплины и преподавателей;
7. проверяет сохранённые шаблоны;
8. предлагает наиболее результативную разметку.

## 2. Предварительная проверка

Кнопка **«Проверить разметку файла»** показывает:

- найденные занятия;
- занятия с преподавателем;
- занятия без преподавателя;
- автоматические исправления;
- календарные подсказки;
- доступные действия оператора.

Проверка не является разрешением на формирование. Предупреждение не блокирует результат.

## 3. Автоматические исправления

Очевидные дефекты разметки исправляются автоматически:

- перепутанные границы;
- координаты за пределами листа;
- неполные списки столбцов;
- несовпадающее число недель и столбцов;
- неполные строки дней и смещения пар;
- отсутствующий выбранный лист при наличии другого листа.

Нажмите **«Показать исправленную разметку»**, чтобы перенести использованные координаты в редактор. После этого их можно изменить вручную.

## 4. Правка на текущем экране

Над листом выберите назначение диапазона:

- сетка занятий;
- строка недель;
- строка месяцев;
- блок дисциплин;
- столбец обозначения;
- столбец дисциплины;
- столбец лектора;
- столбец остальных преподавателей.

Выделите диапазон мышью или пальцем. Для строк и столбцов можно использовать заголовки таблицы; `Shift` расширяет диапазон. Повторная загрузка файла не требуется.

## 5. Календарь и переход месяца

Откройте раздел **«Календарь и переходы месяцев»**.

Последовательная смена месяца внутри недели является нормой. Например:

```text
26, 27, 28, 29 февраля; 1, 2 марта
```

Строка месяцев может содержать только `Февраль`, только `Март` или объединённую подпись. Точные даты имеют приоритет, поэтому такой переход принимается автоматически.

Для каждой недели можно вручную изменить:

- подпись месяца;
- дату понедельника;
- дату вторника;
- дату среды;
- дату четверга;
- дату пятницы;
- дату субботы.

Пустое ручное поле означает автоматический выбор. После изменения нажмите **«Применить и пересчитать»**.

### Способ выбора календаря

- **Автоматически** — ручные правки, точные даты, большинство файлов, строка месяцев, период пространства;
- **Приоритет дат Excel** — использовать исходную последовательность дат;
- **Приоритет пространства** — строить календарь от дат активного пространства.

## 6. Разные семестры и учебные годы

Различающиеся заголовки больше не отменяют формирование. Система использует конкретные даты и показывает замечание. Оператор может:

- оставить автоматический календарь;
- выбрать приоритет Excel;
- выбрать период пространства;
- изменить конкретную дату.

Исходный файл менять не требуется.

## 7. Файл не разобран

Если занятия не найдены, файл остаётся в сеансе. Оператору предлагается указать сетку, недели или слои занятия на том же экране.

Если один файл технически повреждён, он пропускается, а остальные продолжают обрабатываться.

Если занятия не извлечены ни из одного файла, система всё равно создаёт диагностический Excel с перечнем файлов, замечаний и действий.

## 8. Преподаватель не определён

Занятие не удаляется. Оно попадает в раздел **«Не назначен»**. Сохраняются дисциплина, группа, аудитория, дата и пара.

После уточнения справочника или блока преподавателей повторите проверку либо повторите запуск из истории.

## 9. Неделя 0

Неделя `0` поддерживается и означает неделю перед неделей `1`. Не заменяйте её вручную на `1`, если она действительно указана в исходнике.

## 10. Шаблоны

Проверенную разметку можно сохранить как шаблон активного пространства. При следующей загрузке каждый подходящий шаблон запускается на файле, после чего выбирается вариант с наибольшим количеством достоверных занятий.

## 11. Полноэкранная рабочая область

Система отдельно для каждого пространства сохраняет:

- полноэкранный режим;
- видимость списка файлов;
- видимость параметров;
- видимость инструментов разметки;
- масштаб;
- автоматический пересчёт;
- положение и ширину плавающих панелей.

Кнопка **«Сбросить вид»** возвращает исходное расположение текущего пространства.

## 12. Формирование

Кнопка **«Сформировать расписание»** доступна при наличии хотя бы одного читаемого выбранного файла.

Результат может содержать:

- сводное расписание;
- недельное расписание;
- раздел `Не назначен`;
- предупреждения;
- список автоматических исправлений;
- диагностический Excel, если занятия пока не извлечены.

## Типовые ситуации

### Неделя начинается в феврале и заканчивается в марте

Ничего исправлять не требуется. Парсер принимает последовательную смену месяца.

### Пространство настроено на август, а файл начинается в феврале

По умолчанию используются точные даты файла. В панели календаря можно переключить приоритет на пространство, не изменяя Excel.

### Число столбцов не совпадает с числом недель

Система пытается выровнять их автоматически. Использованные координаты отображаются в блоке автоматических исправлений. При необходимости выберите правильные столбцы на листе.

### В наборе есть весенние и осенние файлы

Они сводятся по фактическим датам. Замечание остаётся в отчёте, но экспорт продолжается.

### Один файл повреждён

Остальные файлы используются. Для повреждённого файла показывается отдельное действие; повторная загрузка остальных файлов не нужна.
