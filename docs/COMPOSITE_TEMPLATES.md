# Составные шаблоны и обучение форматов

## Компонент шаблона

Один шаблон может хранить несколько вариантов книг. Компонент содержит:

- идентификатор и понятное название;
- предпочитаемый лист;
- структурный отпечаток;
- координаты `ScheduleLayout`.

## Отпечаток

Отпечаток не содержит содержимое расписания целиком. Он включает безопасные структурные признаки:

- количество строк и столбцов;
- число объединений;
- заголовочные токены;
- ключевые слова;
- расположение последовательностей недель;
- SHA-256 нормализованной структуры.

## Выбор

Система не доверяет одному сходству. Каждый компонент запускается настоящим парсером. Итоговый балл объединяет:

- уникальные занятия;
- назначенных преподавателей;
- недели и дисциплины;
- ошибки, предупреждения и дубли;
- сходство отпечатка;
- статистику подтверждённых успешных и неуспешных применений.

## Обучение

Обучение выполняется только явным действием оператора после проверки файла. Текущая разметка сохраняется новой ревизией, а отпечаток — правилом формата. Самостоятельное изменение координат без подтверждения запрещено.
