# Модель работы редактора оператора

Версия: 2.17+

## Локальная разметка и шаблон — разные сущности

Любое изменение координат, диапазонов, названия группы, календаря или назначения преподавателей сразу относится к текущему файлу и сохраняется в серверном черновике. Для этого не требуется создавать или обновлять шаблон.

Кнопка **«Выйти»** закрывает полноэкранный редактор без диалога сохранения шаблона. Текущие изменения остаются в сеансе и восстанавливаются после обновления страницы.

Кнопка **«Сохранить как шаблон»** выполняет отдельное глобальное действие. Она нужна только тогда, когда подтверждённую геометрию следует автоматически предлагать для будущих похожих книг.

Перед сохранением шаблона интерфейс явно показывает два варианта:

- обновить выбранный шаблон новой ревизией;
- создать новый шаблон.

История старых ревизий не удаляется.

## Undo/redo

Редактор ведёт отдельную историю для каждого файла. В одно состояние входят:

- геометрия листа;
- название группы;
- включение или исключение файла;
- ручные даты и месяцы;
- назначения дисциплин преподавателям;
- общая политика календаря.

Хранится до 80 состояний на файл. После отмены или возврата:

1. сбрасывается устаревшая проверка этого файла;
2. обновляется предпросмотр;
3. новое состояние сохраняется в серверном черновике.

Команды:

- `Ctrl/Cmd + Z` — отменить;
- `Ctrl/Cmd + Shift + Z` — вернуть;
- `Ctrl + Y` — вернуть;
- кнопки `↶` и `↷` в командной панели.

Удаление исходника имеет отдельную отмену **«Вернуть файл»**, поскольку это операция состава сеанса, а не изменение разметки.

## Смена рабочего пространства

Во время активного сеанса смена пространства всегда требует подтверждения. Интерфейс заранее объясняет последствия.

Сохраняются:

- исходные файлы;
- названия групп;
- ручная геометрия;
- календарные правки.

Из нового пространства берутся:

- справочник преподавателей;
- сохранённые шаблоны и их статистика;
- даты периода пространства;
- права и служебные настройки.

Автоподбор шаблонов пересчитывается, но ручная геометрия файлов после пересчёта восстанавливается. Прежние проверки аннулируются, поскольку они использовали другой справочник преподавателей и другой период.

Если ручное назначение указывает на преподавателя, которого нет в новом пространстве, оно не применяется молча: проверка показывает предупреждение, а занятие сохраняется в разделе **«Не назначен»**.

## Безопасные значения по умолчанию

- не найден преподаватель → `Не назначен`;
- не распознан календарь → точные даты, затем соседние месяцы, затем период пространства;
- не извлечены занятия → файл остаётся в диагностическом результате;
- повреждён один файл → остальные продолжают формироваться;
- ошибка презентационного оформления → плоский рабочий XLSX;
- конфликт двух вкладок → более новая серверная ревизия не перезаписывается автоматически.
