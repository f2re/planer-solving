# Серверный черновик рабочего сеанса

Начиная с версии 2.17 состояние оператора сохраняется не только в памяти браузера, но и внутри каталога активного анализа.

## Что сохраняется

- идентификатор рабочего пространства;
- текущий этап и выбранный файл;
- название группы и признак включения каждого исходника;
- разметка каждого файла;
- результаты проверки и структурированные решения;
- ручные даты, месяцы и назначения преподавателей;
- общая политика календаря;
- сформированный результат, чтобы после перезагрузки сохранить путь возврата к исходникам.

Исходные книги не копируются повторно: черновик ссылается только на файлы текущего серверного сеанса.

## Когда сохраняется

Браузер отправляет черновик после изменения с задержкой 750 мс. Перед закрытием страницы выполняется дополнительная отправка с `keepalive`. При временной потере связи интерфейс показывает, что черновик ожидает сохранения, и повторяет попытку после восстановления сети.

## Восстановление

Идентификатор последнего активного сеанса хранится локально в браузере. После входа приложение запрашивает серверный черновик и восстанавливает рабочее пространство, файлы, группы, разметку, календарные решения, проверки и экран результата. Повторная загрузка исходников не требуется, пока серверный сеанс не истёк.

## Две вкладки

Каждая запись имеет монотонную ревизию. Сохранение с устаревшей ревизией получает ответ `409 draft_revision_conflict`; серверная версия не перезаписывается. Интерфейс предлагает явно восстановить более новую серверную версию.

## API

```text
GET    /api/analysis/{session_id}/draft
PUT    /api/analysis/{session_id}/draft
DELETE /api/analysis/{session_id}/draft
```

Максимальный размер JSON-черновика — 8 МБ. Сервер удаляет из черновика ссылки на файлы, которых уже нет в manifest. Запись выполняется атомарно через временный файл и `os.replace`.

## Срок хранения

Черновик находится в каталоге анализа и имеет тот же срок жизни, что и исходники сеанса. Каждое успешное автосохранение обновляет время активности каталога. Штатное действие «Начать заново» удаляет весь сеанс вместе с черновиком.

## Граница гарантии

Черновик защищает от обновления страницы, закрытия браузера и перезапуска веб-службы. Он не заменяет историю сформированных запусков. После истечения срока хранения сеанса восстановить незавершённые исходники нельзя; завершённые результаты остаются в истории согласно политике хранения приложения.
