# Черновик обработки и восстановление сеанса

## Что сохраняется

После загрузки файлов Planner Solving сохраняет не только сами книги Excel, но и текущий операторский черновик:

- включённые и отключённые файлы;
- названия групп;
- выбранный файл;
- исправленную разметку каждого файла;
- ручные даты и месяцы;
- способ выбора календаря;
- текущий этап работы;
- готовый результат и перечень замечаний.

Черновик хранится рядом с исходниками на сервере, а браузер сохраняет только случайный идентификатор сеанса. Поэтому обновление страницы не уничтожает работу.

## Автоматическое сохранение

Изменения отправляются на сервер с небольшой задержкой после редактирования. Внизу рабочей области показывается состояние:

- `Сохраняем изменения…`;
- `Сохранено ЧЧ:ММ`;
- `Черновик не сохранён`.

При закрытии вкладки выполняется дополнительная попытка сохранить последнее состояние. Основным источником остаётся уже записанный серверный черновик.

## Восстановление после обновления страницы

После входа приложение проверяет сохранённый идентификатор сеанса. Если исходники ещё доступны, автоматически восстанавливаются:

1. рабочее пространство;
2. список файлов;
3. выбранный файл;
4. разметка;
5. календарные правки;
6. этап редактора или готовый результат.

Повторно загружать Excel не требуется.

## Срок хранения

Текущий срок хранения сеанса — 24 часа с момента последней активности. Открытие сохранённого сеанса продлевает срок. После истечения приложение удаляет локальную ссылку и сообщает, что требуется новый сеанс.

История завершённых запусков и архивные исходники хранятся отдельно в постоянных данных приложения.

## Возврат из готового результата

Формирование не закрывает сеанс. На странице результата доступны:

- **Вернуться к файлам и правкам**;
- **Открыть и исправить** у файла с замечаниями;
- перечень автоматических и ручных коррекций.

После правки можно повторно сформировать расписание в том же сеансе.

## Замена одного повреждённого файла

Для каждого файла доступна команда:

- **Заменить** — для уже разобранной книги;
- **Выбрать другой** — для файла, который не удалось открыть.

Замена выполняется отдельно. При этом сохраняются:

- все остальные исходники;
- разметки остальных файлов;
- ручные даты;
- выбранный календарь;
- настройки пространства.

Новый файл сначала загружается во временное место и проверяется. Если он пуст, имеет неподдерживаемый формат или снова не читается, прежний файл и черновик остаются без изменений.

## Если не разобрался ни один файл

Система всё равно открывает рабочий сеанс и список файлов. Оператор может заменить каждый файл отдельно. Начинать обработку заново и повторно выбирать все остальные файлы не требуется.

## Уточнение преподавателей

Действие **Уточнить преподавателей** переводит предпросмотр в область `Дисциплины и преподаватели`. После этого можно:

- изменить столбцы лектора и других преподавателей;
- изменить границы нижнего блока;
- открыть справочник активного пространства;
- повторить проверку файла.

## Серверные маршруты

```text
GET  /api/analysis/{session_id}
PUT  /api/analysis/{session_id}/draft
POST /api/analysis/{session_id}/files/{file_id}/replace
```

Восстановительный ответ не содержит внутренних путей сервера и имён сохранённых файлов.
