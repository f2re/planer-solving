# Поддержанные семейства расписаний Excel

Версия 2.10 проверена на обезличенных структурных характеристиках девяти реальных книг. Исходные книги не добавляются в публичный репозиторий: тесты создают эквивалентные таблицы программно.

## Семейство A — короткая шкала

Характерные варианты: группы вида `11161`, `11409`.

- строка недель: 5;
- недельные столбцы начинаются с D;
- строка месяцев: 6;
- начала дней: 8, 21, 34, 47, 60, 73;
- четыре пары со смещениями 0, 3, 6, 9;
- нижний блок начинается со строки 83;
- данные нижнего блока обычно начинаются со строки 86;
- обозначение и название дисциплины находятся слева, лектор и остальные преподаватели — в разнесённых правых столбцах.

## Семейство B — стандартная шкала

Характерные варианты: группы вида `512`, `522`, `532`.

- строка недель: 7;
- недельные столбцы начинаются с E;
- строка месяцев: 8;
- начала дней: 10, 23, 36, 49, 62, 75;
- четыре пары со смещениями 0, 3, 6, 9;
- нижний блок начинается со строки 88;
- данные нижнего блока начинаются со строки 91;
- встречаются опечатки в заголовках, например «Летор» вместо «Лектор»;
- обозначение дисциплины может быть заполнено при пустом полном названии.

## Семейство C — расширенная книга

Характерные варианты: группы вида `542`, `552`.

- до 30 недель;
- встречается неделя 0;
- используются короткие обозначения вида занятия: `Л`, `ПЗ`, `П`, `С`, `Э`;
- встречаются записи `Экзамен/Э`, `ЛТ.11`, `ПР`, `ИКС/ИКС`;
- лектор и остальные преподаватели расположены существенно правее сетки;
- справа и ниже расписания могут находиться расчётные таблицы с числовыми последовательностями;
- расчётные области не должны участвовать в поиске недель, сетки или нижнего блока.

## Семейство D — компактная служебная область

Характерный вариант: книга с полнотекстовыми названиями дней недели.

- строка недель: 4;
- строка месяцев: 5;
- начала дней: 7, 20, 33, 46, 59, 72;
- подписи дней могут быть полными: «понедельник», «вторник» и так далее;
- часть ячеек в строке вида занятия может содержать аудиторию или служебную пометку вместо кода занятия;
- такие ячейки пропускаются, если значение не соответствует обозначению вида занятия.

## Почему сохраняются точные списки координат

Одних параметров «первый столбец / последний столбец / шаг» недостаточно. Заголовок недели может быть объединённым, а данные недели — находиться в соседнем столбце. Поэтому шаблон хранит отдельно:

- точные столбцы заголовков недель;
- точные столбцы данных;
- номера недель;
- строки начала каждого дня;
- смещения начала каждой пары;
- смещения вида занятия, дисциплины, аудитории и преподавателя;
- первую строку данных нижнего блока.

Эти поля доступны оператору в веб-интерфейсе и входят в структурный отпечаток шаблона.
