# Пространства, преподаватели и шаблоны

## Назначение

Пространство — изолированный рабочий контур. При переключении пространства меняются преподаватели, шаблоны и даты семестра. Загруженные Excel-файлы можно продолжать размечать, но после переключения их необходимо проверить повторно, поскольку сопоставление преподавателей изменилось.

## Создание пространства

1. Нажмите **Управление** в верхней панели.
2. Откройте вкладку **Пространства**.
3. Задайте понятное название, например «Кафедра метеорологии — осень 2026».
4. Выберите цвет. Он используется как основной акцент интерфейса и помогает визуально отличать контуры.
5. При необходимости задайте описание и границы семестра.

Можно создать полную копию существующего пространства. Копируются преподаватели, шаблоны и настройки, но создаются новые внутренние идентификаторы.

## Преподаватели

Во вкладке **Преподаватели** доступны поиск, добавление, редактирование и удаление. После изменения списка результаты предыдущей проверки расписаний сбрасываются автоматически.

### CSV

Рекомендуемый заголовок:

```csv
Краткое имя;Полное ФИО;Должность;Звание;Степень
Иванов И.И.;Иванов Иван Иванович;Доцент;доцент;к.т.н.
```

Допустимы русские и английские названия полей. Поддерживается UTF-8 и Windows-1251, разделители `;`, `,` и табуляция.

Режим **Добавить** сохраняет текущие записи и пропускает дубликаты. Режим **Заменить** предварительно очищает список.

## Шаблоны разметки

Шаблоны хранятся на сервере внутри пространства, а не только в браузере.

- **Сохранить как новый** создаёт новый формат.
- **Обновить выбранный** сохраняет текущие координаты, название и описание в существующий шаблон.
- На вкладке управления можно изменить название и описание без изменения координат.
- Экспорт и импорт выполняются в JSON.

При первом запуске старые шаблоны из `localStorage` автоматически переносятся в активное пространство один раз.

## Резервное копирование

Экспорт пространства создаёт единый JSON-пакет. Он содержит преподавателей, шаблоны и настройки. При импорте создаётся новое пространство с новым идентификатором; существующие данные не перезаписываются.

Для регулярного серверного резервного копирования достаточно копировать:

```text
data/workspaces.json
teachers.json
```

`teachers.json` является совместимой копией преподавателей пространства по умолчанию.
