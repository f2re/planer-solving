# Пространства, преподаватели и шаблоны

## Назначение

Пространство — изолированный рабочий контур. При переключении пространства меняются преподаватели, шаблоны и даты семестра. Загруженные Excel-файлы можно продолжать размечать, но после переключения их необходимо проверить повторно, поскольку сопоставление преподавателей изменилось.

Данные одного пространства не подмешиваются в другое. Новое пространство создаётся пустым, если оператор явно не выбрал действие **«Создать копию»**.

## Миграция прежних данных

Данные, существовавшие до введения пространств, имеют единственного владельца — **«Основное пространство»**.

- прежний `teachers.json` переносится только в основное пространство;
- старые шаблоны браузера из `localStorage` переносятся только в основное пространство независимо от того, какое пространство открыто в момент обновления;
- top-level `teachers`, `templates` и `layout_profiles` в прежнем JSON при миграции консолидируются только в основном пространстве и удаляются из глобального уровня;
- данные не копируются автоматически в остальные пространства;
- запросы проверки и формирования расписания обязаны содержать явный `workspace_id`, поэтому сервер не выбирает пространство молча.

Если пространство с названием **«Основное пространство»** существует, именно оно считается владельцем legacy-данных. Если оно было переименовано, используется сохранённое пространство по умолчанию. Повторная миграция идемпотентна и не создаёт дубликаты.

## Создание пространства

1. Нажмите **Управление** в верхней панели.
2. Откройте вкладку **Пространства**.
3. Задайте понятное название, например «Кафедра метеорологии — осень 2026».
4. Выберите цвет. Он используется как основной акцент интерфейса и помогает визуально отличать контуры.
5. При необходимости задайте описание и границы семестра.

Можно создать полную копию существующего пространства. Это отдельное явное действие: копируются преподаватели, шаблоны и настройки, но создаются новые внутренние идентификаторы. Обычное создание пространства ничего не копирует.

## Преподаватели

Во вкладке **Преподаватели** доступны поиск, добавление, редактирование и удаление. После изменения списка результаты предыдущей проверки расписаний сбрасываются автоматически.

### CSV

Рекомендуемый заголовок:

```csv
Краткое имя;Полное ФИО;Должность;Звание;Степень
Иванов И.И.;Иванов Иван Иванович;Доцент;доцент;к.т.н.
```

Допустимы русские и английские названия полей. Поддерживается UTF-8 и Windows-1251, разделители `;`, `,` и табуляция.

Режим **Добавить** сохраняет текущие записи и пропускает дубликаты. Режим **Заменить** предварительно очищает список.

## Шаблоны разметки

Шаблоны хранятся на сервере строго внутри выбранного пространства, а не глобально и не только в браузере.

- **Сохранить как новый** создаёт новый формат в текущем пространстве.
- **Обновить выбранный** сохраняет текущие координаты, название и описание в существующий шаблон этого пространства.
- На вкладке управления можно изменить название и описание без изменения координат.
- Экспорт и импорт выполняются в JSON.

Старые локальные шаблоны, созданные до поддержки пространств, при первом переносе закрепляются только за **«Основным пространством»**. Они не становятся общими для других пространств.

## Резервное копирование

Экспорт пространства создаёт единый JSON-пакет. Он содержит преподавателей, шаблоны и настройки. При импорте создаётся новое пространство с новым идентификатором; существующие данные не перезаписываются.

Для регулярного серверного резервного копирования достаточно копировать:

```text
data/workspaces.json
teachers.json
```

`teachers.json` является совместимой копией преподавателей пространства по умолчанию и не является общим справочником для всех пространств.
