# Выпуск 2.9.0

## Основные изменения

- предварительный интерактивный импорт;
- локальные пользователи, роли и защищённые сеансы;
- журнал действий;
- ревизии шаблонов, сравнение и откат;
- составные шаблоны;
- структурные отпечатки Excel;
- подтверждаемое обучение форматов;
- история обработок, исходников и результатов;
- повтор запуска из истории;
- контрольные суммы сохранённых файлов.

## Обновление

Штатный `start_web.sh` или офлайн-установщик автоматически создаёт новые таблицы в существующей SQLite-базе. Пространства, преподаватели и шаблоны сохраняются. Для каждого старого шаблона создаётся начальная ревизия №1.

После первого запуска интерфейс потребует создать первоначального администратора. До этого рабочие API изменения недоступны.
