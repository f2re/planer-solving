# Восстановление расписаний без блокировки

## Основной принцип

Предварительная проверка не выдаёт разрешение на формирование. Она показывает, что система распознала уверенно, что исправила автоматически и что оператор может уточнить. Любой читаемый файл можно отправить на формирование.

## Переход месяца внутри недели

Неделя может содержать даты двух соседних месяцев. Пример:

```text
Пн 26 февраля
Вт 27 февраля
Ср 28 февраля
Чт 29 февраля
Пт 1 марта
Сб 2 марта
```

Подпись над столбцом может быть `Февраль`, `Март` или объединённая ячейка на несколько недель. Это оформление, а не ошибка данных. Парсер принимает последовательность дат и сохраняет переход месяца автоматически.

## Автоматические исправления разметки

Система безопасно исправляет:

- перепутанные начало и конец диапазона;
- координаты за пределами листа;
- несовпадающее количество столбцов недель и данных;
- неполный список строк дней;
- неполный список смещений пар;
- отсутствующий лист, если в книге есть другой лист;
- нераспознанные номера недель при понятном порядке столбцов.

Использованная разметка показывается оператору кнопкой **«Показать исправленную разметку»**. После применения её можно менять обычными инструментами выделения.

## Ручная правка даты

После проверки откройте раздел **«Календарь и переходы месяцев»**. Для каждой недели доступны:

- распознанная подпись месяца;
- ручная подпись месяца;
- распознанная дата каждого дня;
- ручная дата каждого дня.

Пустое ручное поле означает автоматический выбор. После изменения нажмите **«Применить и пересчитать»**. Файл повторно загружать не требуется.

## Выбор общего календаря

Доступны три режима:

- **Автоматически** — ручные правки, точные даты, большинство файлов, подписи месяцев, период пространства;
- **Приоритет дат Excel** — использовать фактическую шкалу исходников;
- **Приоритет пространства** — строить шкалу от настроенных дат пространства.

Автоматический режим рекомендуется по умолчанию.

## Частичная обработка

Если один файл не разобран:

- остальные файлы продолжают обрабатываться;
- исходный файл остаётся в сеансе;
- в результате указывается, какие файлы использованы;
- оператор получает действие для исправления конкретного файла.

Если ни одного занятия пока не извлечено, создаётся диагностический Excel. Это завершённый результат текущей попытки, а не отказ сервера.

## Неназначенный преподаватель

Занятие без уверенно найденного преподавателя помещается в раздел **«Не назначен»**. Дисциплина, группа, аудитория, неделя и пара сохраняются.

## Сохранение вида

Состояние рабочей области хранится в браузере отдельно для каждого пространства. Сохраняются масштаб, панели и их координаты. Кнопка **«Сбросить вид»** удаляет сохранённую раскладку текущего пространства.
