# Planner Solving 2.17 — рабочее место оператора

## Основной результат

Версия 2.17 переводит систему от набора технических экранов к неблокирующему операторскому процессу. Результат строится из всех пригодных данных, каждое сомнение имеет безопасное решение по умолчанию, а оператор может изменить решение без перезапуска всей обработки.

## Серверный черновик

Автоматически сохраняются:

- состав активного сеанса;
- названия групп;
- включение файлов;
- геометрия каждого листа;
- результаты проверок;
- календарные правки;
- назначения преподавателей;
- готовый результат и текущий экран.

После обновления страницы или перезапуска веб-службы сеанс восстанавливается, пока исходники не удалены политикой хранения. Ревизии не позволяют одной вкладке молча перезаписать более новый черновик другой вкладки.

## Операции с отдельным файлом

В активном сеансе доступны:

- добавление новых книг без изменения уже исправленных;
- атомарная замена одного файла;
- сохранение группы и совместимой ручной разметки при замене;
- отклонение повреждённой замены без потери прежнего исходника;
- удаление файла с немедленной отменой;
- транзакционный откат файловой операции при сбое записи manifest.

## Решения и преподаватели

Все сообщения парсера приводятся к структуре `Issue/Resolution`:

- область проблемы;
- сообщение;
- безопасное решение по умолчанию;
- влияние на результат;
- ручное действие оператора;
- признак автоматического или операторского решения.

Неизвестный преподаватель не приводит к потере занятия. По умолчанию используется раздел **«Не назначен»**. Оператор может назначить преподавателя каждой дисциплине прямо из общей очереди решений.

## Редактор

Локальная разметка файла и глобальный шаблон разделены:

- выход из редактора не требует сохранять шаблон;
- файл уже сохранён в серверном черновике;
- шаблон меняется только явной командой **«Сохранить как шаблон»**;
- диалог объясняет, что шаблон влияет на будущие похожие книги.

Добавлена история до 80 состояний на каждый файл. Undo/redo охватывает геометрию, группу, включение файла, календарь и ручные назначения.

Горячие клавиши:

- `Ctrl/Cmd + Z` — отменить;
- `Ctrl/Cmd + Shift + Z` — вернуть;
- `Ctrl + Y` — вернуть.

## Смена пространства

Переключение пространства во время активного сеанса требует подтверждения. Файлы, группы, ручная геометрия и календарные правки сохраняются. Преподаватели, шаблоны и период берутся из нового пространства, после чего проверки явно помечаются как требующие пересчёта.

Автоподбор шаблонов нового пространства не перезаписывает ручную геометрию оператора.

## История запусков

- технические статусы переведены на русский язык;
- по каждому исходнику доступен список сохранённых решений;
- показываются значение по умолчанию и влияние на результат;
- старый запуск можно повторить с архивными исходниками и прежней разметкой.

## Отказоустойчивый экспорт

Если презентационное оформление основного XLSX завершается ошибкой, создаётся плоская рабочая книга с восстановленными данными и диагностикой. Ошибка оформления не оставляет оператора без скачиваемого результата.

## Следующий архитектурный этап

Функциональная модель реализована. Следующий этап уменьшает технический долг интерфейса:

1. перенос оставшихся `insertAdjacentHTML` в декларативные Vue-компоненты;
2. объединение «Управления» и «Центра операций»;
3. единый контекстный инспектор редактора;
4. браузерные сценарии доступности, фокуса и масштаба 200%;
5. явная state machine жизненного цикла сеанса.
